# Student Performance Analysis Dashboard

Interactive Power BI dashboard analyzing factors that affect student exam performance, built on a dataset of 6,607 students.

## Objective
To understand how study habits, attendance, sleep, parental involvement and other factors relate to students' exam scores.

## Dataset
- File: `StudentPerformanceFactors.csv`
- 6,607 student records
- Columns include Hours_Studied, Attendance, Sleep_Hours, Exam_Score, Gender, Parental_Involvement, Motivation_Level, Tutoring_Sessions and more

## Tools Used
- Power BI Desktop
- DAX (calculated column Result, and measures for Total, Passed and Failed Students)

## Dashboard Pages
1. **Overview:** KPI cards, average exam score by study hours, pass vs fail
2. **Gender Analysis:** student count, share and failed students by gender
3. **Study Habits:** exam score by physical activity, motivation, tutoring and study hours
4. **Performance Factors:** parental involvement, education, learning disabilities and internet access

- Average exam score is about 67, average attendance about 80%, average study time about 20 hours
- Male students are about 58% and female students about 42% of the dataset
